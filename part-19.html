1. Process — কী, কেন, কীভাবে, না হলে কী

কী

Process মানে একটা ধারাবাহিক ধাপের সমষ্টি, যার মাধ্যমে Input (কাঁচামাল) কে Output (পণ্য) তে রূপান্তর করা হয়।

Bag Factory তে Process = Material Inspection → Cutting → Skiving → Pre-assembly → Stitching → Finishing → QC → Packing।

Process এর ৪ উপাদান (4M)

উপাদানঅর্থBag Factory Example
ManলোকOperator, Supervisor, Inspector
Machineযন্ত্রSewing Machine, Skiving Machine
MaterialকাঁচামালLeather, Thread, Zipper, Rivet
Methodপদ্ধতিSOP, Stitch Type, Jig/Folder

কেন Process দরকার

  • প্রতিদিন একই মানের পণ্য বানাতে।
  • নতুন Operator কে Training দিতে।
  • সমস্যা হলে কোথায় হয়েছে তা খুঁজে বের করতে।
  • Efficiency, Capacity, Costing হিসাব করতে।

না হলে কী হবে

⚠️ Process ঠিক না থাকলে: Operator নিজের ইচ্ছামতো কাজ করবে, মান হবে না, Training দিতে পারবে না, Capacity বা Costing ঠিক হবে না, Buyer Audit এ ফেল করবে।
💡 Productivity তে প্রভাব: Process Standard হলে Variation কমে, Training সহজ হয়, Efficiency বাড়ে। প্রায় ১০-১৫% Productivity বাড়ে শুধু Process ঠিক রাখলেই।

2. Capacity — Basic ধারণা (৪ প্রকার)

কী

Capacity হলো একটা Line বা Factory নির্দিষ্ট সময়ে সর্বোচ্চ কত Output দিতে পারে।

Capacity এর ৪ প্রকার

প্রকারঅর্থ
Design Capacityতাত্ত্বিক সর্বোচ্চ ক্ষমতা (১০০% Efficiency তে)
Effective Capacityবাস্তব সীমাবদ্ধতা (Breakdown, Shift) মেনে ক্ষমতা
Actual Outputযা সত্যি উৎপাদিত হলো
Available Capacityএখন কতটুকু খালি আছে (নতুন Order এর জন্য)

কেন Capacity জানা দরকার

  • নতুন Order নেওয়ার আগে — পারবো কি না?
  • Delivery তারিখ ঠিক করতে।
  • কয়টা Line লাগবে হিসাব করতে।
  • Costing এ CM বের করতে।
  • Bottleneck কোথায় তা বোঝার জন্য।
⚠️ Capacity না জানলে: অতিরিক্ত Order নিয়ে Delivery মিস হবে, Air Shipment, জরিমানা। কম Order নিলে Line খালি বসে থাকবে, লোকসান।

3. Man Capacity — এক TM

কী

Man Capacity মানে নির্দিষ্ট সংখ্যক Operator (TM = Total Manpower) দিয়ে নির্দিষ্ট সময়ে সর্বোচ্চ কত Output দেওয়া যায়।

Formula

Man Capacity = (TM × WH × Efficiency) ÷ SMV TM = Total Manpower, WH = Working Hours (মিনিটে), Efficiency = ১০০% ধরা হয় Utilization এ
অথবা, Man Capacity = (TM × WH) ÷ B.H B.H = SMV এর Hour Format = SMV ÷ 60

Example (কাল্পনিক)

TM = ১৭ জন
WH = 480 মিনিট/দিন
SMV = 11.34 মিনিট (= B.H 0.189 ঘণ্টা)

১০০% Efficiency তে:
Man Capacity = (17 × 480) ÷ 11.34 = 720 Bag/দিন

৭০% Efficiency তে (বাস্তব):
Man Capacity = (17 × 480 × 0.70) ÷ 11.34 = 504 Bag/দিন
✅ মনে রাখো: Utilization বের করার জন্য Man Capacity ১০০% এ বের করো। Efficiency বের করার জন্য Actual Efficiency দিয়ে বের করো।

4. Man Capacity — Multi TM

কী

যখন একাধিক TM একই Operation এ কাজ করে, তখন মোট Capacity বের করতে হয়।

Formula

Multi TM Capacity = (মোট TM × WH × Efficiency) ÷ SMV মোট TM = একসাথে কাজ করা সব Operator এর সংখ্যা

Example (কাল্পনিক): ৩ TM একই Operation

৩ জন Operator একসাথে Zipper লাগায়
প্রতি TM = 480 মিনিট
SMV = 2.5 মিনিট/Operation
Efficiency = 70%

মোট TM-Minutes = 3 × 480 = 1,440
Efficiency সহ = 1,440 × 0.70 = 1,008
Capacity = 1,008 ÷ 2.5 = 403 Piece/দিন
✅ মনে রাখো: Multi-TM এ প্রতিটা TM আলাদা Capacity দিলেও, মোট Capacity = সব TM এর Capacity এর সমষ্টি।

5. Machine Capacity — Single Process

কী

Machine Capacity মানে একটা Machine নির্দিষ্ট সময়ে সর্বোচ্চ কত Operation করতে পারে, যখন একটাই Process করে।

Formula

Machine Capacity = (Planned Time × Efficiency) ÷ Cycle Time Cycle Time = Operation এর SMV বা TM Process Cycle Time
অথবা, TM Capacity = 3600 sec ÷ TM Process Cycle Time (sec) এটা ঘণ্টায় কত Piece — Ventura Formula #8

Example (কাল্পনিক)

একটা Flatbed Machine, Operation = Pocket Stitch
Planned Time = 480 মিনিট/দিন
Efficiency = 75%
Cycle Time = 0.90 মিনিট

Machine Capacity = (480 × 0.75) ÷ 0.90 = 400 Pocket/দিন
✅ মনে রাখো: Single Process Machine এ Capacity সরাসরি সময় ÷ Cycle Time।

6. Machine Capacity — Multi Process

কী

একটা Machine যখন একাধিক Process করে (যেমন Post-bed দিয়ে Pocket, Zipper, Handle), তখন সময় ভাগ করে দিতে হয়। এটাই Multi-Process Capacity।

Formula

প্রতিটা Process এর Capacity = (Process এ বরাদ্দ সময় × Efficiency) ÷ Process এর Cycle Time সব Process এর Capacity যোগ করলে মোট Capacity নয় — বরং প্রতিটার আলাদা Capacity
Machine এর Lowest Capacity = min(Process A Capacity, Process B Capacity, ...) এটাই Machine এর Bottleneck Capacity

Example (কাল্পনিক): Post-bed Machine ৩ Process করে

Planned Time = 480 মিনিট/দিন
Efficiency = 75%

বরাদ্দ:
Process A (Pocket): 200 মিনিট, Cycle 0.90 → Capacity = 200 × 0.75 ÷ 0.90 = 167
Process B (Zipper): 150 মিনিট, Cycle 0.60 → Capacity = 150 × 0.75 ÷ 0.60 = 187
Process C (Handle): 130 মিনিট, Cycle 0.75 → Capacity = 130 × 0.75 ÷ 0.75 = 130

Machine Lowest Capacity = 130 Piece (Process C)
⚠️ সতর্কতা: Multi-Process Machine এ সব Process এর Capacity যোগ করলে ভুল হবে। প্রতিটার Capacity আলাদা, কারণ সময় ভাগ হয়ে গেছে।

7. Lowest Capacity — Bottleneck

কী

Lowest Capacity মানে সব Process বা Machine এর মধ্যে সবচেয়ে কম Capacity — যেটা পুরো Line এর Output কে সীমিত করে। এটাই Bottleneck।

কীভাবে বের করে

  1. প্রতিটা Process এর Capacity বের করো।
  2. সব Capacity এর মধ্যে সবচেয়ে কম কোনটা — সেটাই Lowest Capacity।
  3. এই Process বা Machine কেই আগে ঠিক করতে হবে।
  4. ঠিক করার পর আবার সব Capacity বের করো — নতুন Lowest Capacity আসবে।
Example:
Process A Capacity = 400
Process B Capacity = 380
Process C Capacity = 320 ← Lowest / Bottleneck
Process D Capacity = 350

Line এর সর্বোচ্চ Output = 320 Piece
মানে বাকি Process গুলো ৩২০ পিসের বেশি বানাতে পারলেও, লাইন থেকে বেরোবে ৩২০টাই।
✅ মনে রাখো: Bottleneck ঠিক করার পর নতুন Bottleneck আসবে। এটা চক্রাকারে চলতে থাকে।

8. Utilization — Basic (Efficiency ১০০%)

কী (Definition)

Utilization মানে Capacity এর কতটা ব্যবহার হচ্ছে। তোমার Factory র নিয়মে Utilization এ Efficiency = ১০০% ধরা হয় — অর্থাৎ আমরা দেখি আদর্শ অবস্থায় Capacity এর কতটা ব্যবহার হচ্ছে।

কেন Efficiency ১০০% ধরা হয়

  • Utilization মাপে কতটা কাজ পেয়েছি এবং কতটা করেছি।
  • Efficiency মাপে কতটা ভালো করেছি।
  • দুটো মিশিয়ে ফেললে বোঝা যাবে না — সমস্যা Capacity তে না Efficiency তে।

২টি আলাদা হিসাব

১. Capacity Utilization = Actual Output ÷ Capacity(১০০%) × ১০০
(মানে Capacity এর কতটা ব্যবহার হয়েছে)

২. Capacity Coverage = Capacity(১০০%) ÷ Target × ১০০
(মানে Target পূরণ করতে কতটা Capacity আছে)

Step-by-Step Example: Capacity Coverage

প্রশ্ন: Line C5, 10 hours, Target 300 pcs, Machine Process Time 140 sec/pc। Capacity Coverage কত?

ধাপ ১: Available Time বের করো (সেকেন্ডে)
Available Time = 10 × 60 × 60 = 36,000 sec

ধাপ ২: Machine Capacity বের করো
Capacity = 36,000 ÷ 140 = 257.14 pcs

ধাপ ৩: Capacity Coverage
Coverage = 257.14 ÷ 300 × 100 = 85.71%

উত্তর: Target এর ৮৫.৭১% Capacity আছে। বাকি ১৪.২৯% ঘাটতি (Bottleneck)।
⚠️ সতর্কতা: Capacity Coverage কখনো ১০০% এর বেশি হতে পারে না (অসম্ভব)। যদি বেশি আসে, বুঝবে Target > Capacity — মানে Machine দিয়ে Target পূরণ সম্ভব না।

9. Man Utilization

কী (Definition)

Man Utilization মানে TM (Total Manpower) দের কতটা সময় আসলে কাজে লেগেছে। এক TM বা Multi TM — দুটোতেই কাজ করে।

Formula

Man Utilization (%) = (Earned Minutes ÷ Available Man-Minutes) × 100
Earned Minutes = Output × SMV
Available Man-Minutes = TM × WH

Step-by-Step Example: Simple

প্রশ্ন: ১৭ জন TM, 480 মিনিট, SMV 11.34, Actual Output 500 Bag। Man Utilization কত?

ধাপ ১: Earned Minutes বের করো
Earned = 500 × 11.34 = 5,670 মিনিট

ধাপ ২: Available Minutes বের করো
Available = 17 × 480 = 8,160 মিনিট

ধাপ ৩: Man Utilization
Utilization = 5,670 ÷ 8,160 × 100 = 69.5%

উত্তর: Man Utilization = 69.5%। বাকি ৩০.৫% সময় Idle বা Waste এ গেছে।

10. Machine Utilization

কী (Definition)

Machine Utilization মানে Machine এর কতটা সময় আসলে চলেছে — কতটা বন্ধ ছিল (Breakdown, Setup, Idle)।

Formula

Machine Utilization (%) = (Planned Time − Downtime) ÷ Planned Time × 100 Downtime = Breakdown + Setup + No Load + Idle

Step-by-Step Example: Single Process Machine

প্রশ্ন: Planned = 480 মিনিট, Breakdown = 30, Setup = 40, Idle = 20। Utilization কত?

ধাপ ১: মোট Downtime বের করো
Downtime = 30 + 40 + 20 = 90 মিনিট

ধাপ ২: Machine Utilization
Utilization = (480 − 90) ÷ 480 × 100 = 81.25%

উত্তর: Machine ৮১.২৫% সময় চলেছে, ১৮.৭৫% বন্ধ ছিল।

11. Capacity Utilization

কী (Definition)

Capacity Utilization মানে পুরো Line বা Factory র Capacity এর কতটা ব্যবহার হচ্ছে। এখানে Actual Output কে Capacity(১০০%) দিয়ে ভাগ করা হয়।

Formula

Capacity Utilization (%) = Actual Output ÷ Capacity(১০০%) × 100

Step-by-Step Example

প্রশ্ন: Design Capacity (১০০%) = 720 Bag/দিন, Actual Output = 504 Bag/দিন। Capacity Utilization কত?

ধাপ ১: Capacity Utilization
Utilization = 504 ÷ 720 × 100 = 70%

উত্তর: Capacity এর ৭০% ব্যবহার হয়েছে, ৩০% খালি আছে।

12. Lowest Capacity Utilization

কী (Definition)

Lowest Capacity Utilization মানে সব Process বা Machine এর মধ্যে সবচেয়ে কম Utilization — যেটা সবচেয়ে দুর্বল। এটাই Improvement এর মূল Target।

কীভাবে বের করে

  1. প্রতিটা Process এর Actual Output ও Design Capacity বের করো।
  2. প্রতিটার Utilization = Actual ÷ Design × 100।
  3. সবচেয়ে কম Utilization — সেটাই Lowest Capacity Utilization।
  4. এই Process বা Machine কেই আগে ঠিক করতে হবে।

Step-by-Step Example

প্রশ্ন: ৪টা Process এর Capacity ও Actual Output দেওয়া আছে। Lowest Capacity Utilization কোনটা?

ধাপ ১: প্রতিটার Utilization বের করো
Process A: Capacity 400, Actual 320 → 320 ÷ 400 × 100 = 80%
Process B: Capacity 380, Actual 300 → 300 ÷ 380 × 100 = 78.9%
Process C: Capacity 320, Actual 210 → 210 ÷ 320 × 100 = 65.6%
Process D: Capacity 350, Actual 290 → 290 ÷ 350 × 100 = 82.9%

ধাপ ২: Lowest চিহ্নিত করো
Lowest = 65.6% (Process C)

উত্তর: Lowest Capacity Utilization = 65.6% (Process C)। এটাই Bottleneck, এখানেই Improvement দরকার।

13. TM Capacity (3600 ÷ Cycle Time)

কী

TM Capacity মানে একটা Machine বা TM এক ঘণ্টায় সর্বোচ্চ কত Piece করতে পারে। এটা Ventura Formula #8।

Formula

TM Capacity = 3600 sec ÷ TM Process Cycle Time (sec) 3600 sec = 1 ঘণ্টা

Example

TM Process Cycle Time = 40 সেকেন্ড
TM Capacity = 3600 ÷ 40 = 90 Piece/ঘণ্টা
✅ মনে রাখো: এটা Hourly Capacity। দিনে ৮ ঘণ্টায় = 90 × 8 = 720 Piece/দিন।

14. Efficiency — Basic

কী

Efficiency মানে Standard এর তুলনায় কতটা ভালো কাজ করেছি।

Formula

Efficiency (%) = (Output × SMV) ÷ (TM × WH) × 100 TM = Total Manpower, WH = Working Hours (মিনিটে)
অথবা, = Earned Minutes ÷ Available Man-Minutes × 100

Example

Output = 500 Bag, SMV = 11.34
TM = 17, WH = 480

Earned Minutes = 500 × 11.34 = 5,670
Available = 17 × 480 = 8,160
Efficiency = 5,670 ÷ 8,160 × 100 = 69.5%
⚠️ না হলে কী হবে: Efficiency ৬০% মানে প্রতি ১০০ মিনিটের মধ্যে ৪০ মিনিট অপচয়। Cost বাড়ে, Delivery দেরি হয়।

15. TM Efficiency

কী

TM Efficiency মানে Machine বা TM এর Efficiency — Ventura Formula #10।

Formula

TM Efficiency = (Total Unit × B.H × 100) ÷ Total Minute Worked B.H = SMV in Hour = SMV ÷ 60। Total Unit = উৎপাদিত Piece। Total Minute Worked = Actual Working Minutes।

Example

Total Unit = 400 Piece
B.H = 0.189 (11.34 ÷ 60)
Total Minute Worked = 400 মিনিট

TM Efficiency = (400 × 0.189 × 100) ÷ 400
= 75.6 ÷ 400 × 100 = 18.9%?

⚠️ এটা কম দেখাচ্ছে কারণ Minute এ হিসাব।

সঠিক: আসলে Total Minute Worked = WH (৪৮০) ধরা হয়।
TM Efficiency = (400 × 0.189 × 100) ÷ 480 = 75.6 ÷ 4.80 = 15.75%?

⚠️ এটাও কম। আসল হিসাব:
Total Unit × B.H = Earned Hours = 400 × 0.189 = 75.6 ঘণ্টা
Total Minute Worked = 480 × TM = 8,160 ÷ 60 = 136 ঘণ্টা
TM Efficiency = 75.6 ÷ 136 × 100 = 55.6%
✅ মনে রাখো: B.H ঘণ্টায়, তাই Total Minute Worked কেও ঘণ্টায় নিতে হবে (÷ 60)।

কেন দুটো আলাদা

✅ মনে রাখো:
Utilization = "Capacity এর কতটা ব্যবহার করেছি?"
Efficiency = "Standard এর কতটা অর্জন করেছি?"
Utilization = ১০০% Efficiency ধরে হিসাব।
Efficiency = Actual Efficiency দিয়ে হিসাব।
Example: Line Capacity ৭২০ (১০০%), Actual Output ৫০০

Utilization = 500 ÷ 720 × 100 = 69.4%
মানে Capacity এর ৬৯.৪% ব্যবহার হয়েছে।

Efficiency = (500 × 11.34) ÷ (17 × 480) × 100 = 69.5%
মানে Standard এর ৬৯.৫% অর্জিত।

দুটো এখানে কাছাকাছি, কারণ Efficiency ও Utilization একই ভিত্তিতে।

যখন দুটো আলাদা দেখাবে

💡 Example: যদি Machine এর Speed Standard এর চেয়ে ২০% কম থাকে, তাহলে:
• Machine Utilization = ৯০% (সময় কাজে লেগেছে)
• Machine Efficiency = ৭২% (কম গতিতে কাজ হয়েছে)
এখানে Utilization বেশি কিন্তু Efficiency কম — কারণ Machine চললেও Slow।

17. Ventura Basic Formula Sheet (১৫টি)

তোমার Factory তে যে Formula গুলো ব্যবহার হয় — সব একসাথে, সহজ ব্যাখ্যা সহ।

1. Takt Time
Takt Time = Available Time ÷ Customer Demand Customer চাহিদা অনুযায়ী প্রতি Piece এ কত সময় দরকার
2. Balancing Efficiency
Balancing Efficiency = Σ Cycle Time ÷ (Number of TM × Highest Cycle Time) × 100% Line কতটা সমানভাবে ভাগ হয়েছে। Highest Cycle Time = Bottleneck
3. Idle / Loss Time
Idle / Loss Time = (Non-Balancing Efficiency ÷ 100) × (Number of TM × WH × 60) Non-Balancing Efficiency = 100 − Balancing Efficiency
4. First Hour Output
First Hour Output = Achieved Quantity ÷ Hourly Target × 100% প্রথম ঘণ্টায় Target এর কত % হয়েছে
5. Target
Target = (Number of TM × WH) ÷ B.H B.H = SMV ÷ 60 (SMV in Hour)
6. LT_SPF (Lead Time Single Piece Flow)
LT_SPF = Σ PCT + (X − 1) × PCT_BN PCT = Process Cycle Time, PCT_BN = Bottleneck Process Cycle Time, X = Total Process সংখ্যা
7. Lead Time
Lead Time = Σ xₙ(α) সব Process এর সময় যোগ (α = Cycle Time)
8. TM Capacity
TM Capacity = 3600 sec ÷ TM Process Cycle Time (sec) এক ঘণ্টায় কত Piece
9. Line WIP
Line WIP = Input − Output Line এ জমে থাকা কাজ
10. TM Efficiency
TM Efficiency = (Total Unit × B.H × 100) ÷ Total Minute Worked B.H = SMV ÷ 60, Total Minute Worked = Actual Minutes (Hour এ নিতে হবে)
11. QCO Time
QCO Time = [(A − B) Time + (C − D) Time] ÷ 2 Style Change Over এর গড় সময়
12. Non-Value Added Time
NVA Time = WIP ÷ Target per Day কত দিনের WIP জমে আছে
13. VAR (Value Added Ratio)
VAR = VA Time ÷ (VA Time + NVA Time) × 100% Value Added এর শতকরা অংশ
14. Value Added Time
Value Added Time = Σ Process Cycle Time মোট মূল্য যোগ হওয়া সময়
15. FTT (First Time Through)
FTT = (IPQC Rate × FQC Rate) ÷ 100 IPQC = In-Process QC, FQC = Final QC

19. সাধারণ ভুল

⚠️ ভুল ১: Utilization ও Efficiency কে এক ভাবা।
সঠিক: Utilization = Efficiency ১০০% ধরে, Efficiency = Actual ধরে।
⚠️ ভুল ২: Multi-Process Machine এ সব Process এর Capacity যোগ করা।
সঠিক: সময় ভাগ হয়, তাই প্রতিটার Capacity আলাদা।
⚠️ ভুল ৩: Lowest Capacity না দেখে শুধু Average দেখা।
সঠিক: Lowest Capacity = Bottleneck, ওটাই আগে ঠিক করতে হয়।
⚠️ ভুল ৪: Multi TM এর Capacity ভাগ করে ফেলা।
সঠিক: Multi TM এর Capacity = সব TM এর যোগফল।
⚠️ ভুল ৫: B.H কে মিনিটে রাখা।
সঠিক: B.H = SMV ÷ 60 (ঘণ্টায়)।
⚠️ ভুল ৬: TM Capacity 3600 ÷ Cycle Time এ Cycle Time মিনিটে দেওয়া।
সঠিক: Cycle Time সেকেন্ডে দিতে হবে।
